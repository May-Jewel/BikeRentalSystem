# BikeRentalSystem
An application for managing bike rentals, user accounts, and inventory tracking. 
Built using C# and .NET 8 Windows Forms.  
FeaturesRole-Based Access Control: 
Role-differentiated capabilities for admin and standard customer users.  
Customer Capabilities:
  -Browse available bikes.  
  -View detailed specifications for specific bikes.  
  -Rent bikes by duration (hourly rate calculation).  
  -Check out active rentals and complete payments.  
  -Return rented bikes and view rental history.  
Admin Capabilities:
  -Inventory management: Add, edit status/price/condition, or remove bikes. 
  -Monitor active and past rental transactions.  
  -View aggregate daily rental revenue totals.
